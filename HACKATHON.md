## Selected Problem Statement

**Problem 05 – Automated Documentation Drift Detection**

## Project Name

**DocGuard – AI-Powered Documentation Drift Detection**

## AI Model

**Qwen3 4B – Open-weight language model, intended to run locally through Ollama.**

### Reason for Selecting Qwen3

We selected Qwen3 because it supports local inference and can perform semantic analysis of code changes and technical documentation.

The model will help identify potential inconsistencies between modified source code and existing documentation, explain detected documentation drift, and suggest corrections.

Our implementation will combine deterministic static analysis with AI-powered semantic verification. Findings will be supported by references to the relevant code changes and documentation.

## Planned AI Integration

- Runtime: Ollama
- Model: Qwen3 4B
- Primary use: Semantic documentation drift detection, explanations, and correction suggestions.

The model will be integrated into the actual application; AI usage will be documented according to the implementation.
